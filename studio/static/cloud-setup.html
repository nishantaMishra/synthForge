Connect your AWS account and launch a small text demonstration. Your users will sign in to Synth Forge; they will never need an AWS account ID or registry token.

No AWS resources or payment plans are created by opening this page. A quota request does not start a GPU. AWS credits can offset eligible charges, but they are not a hard spending limit.
